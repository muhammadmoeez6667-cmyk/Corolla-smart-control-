# Corolla Smart Control (Android demo)

This is a native Android Studio project for a visual demo interface for a 2017 Toyota Corolla.

## Important
The current app is **demo-only**. It does not control a real car. Do not connect generic relay boards or DIY electronics directly to ignition, airbags, CAN bus, or other vehicle wiring. Real vehicle control requires a compatible automotive-grade module, a qualified installer, safety interlocks, and a documented communication protocol.

## Build APK
1. Open this folder in Android Studio (recent version).
2. Let Gradle sync.
3. Choose **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. Android Studio will show the generated APK location.

No car hardware is required to run the demo.
